# YÊU CẦU ĐẦU RA

## PHẦN 1: PHÂN TÍCH LỖI

### 1. Tại sao định dạng thủ công khiến Auto TOC không hoạt động?

- Cơ chế: Tính năng mục lục tự động  trong Word chỉ quét các đoạn văn bản được gán nhãn hệ thống chuẩn.

- Nguyên nhân: Các tiêu đề trong bài dùng định dạng thủ công.

### 2. Ảnh hưởng của việc nhầm lẫn cấp độ Heading
Việc gắn nhãn sai cấp sẽ làm cho độ thụt lề trong bảng mục lục bị lệch pha sai cấu trúc phần tử của chương

## PHẦN 2: SỬA LỖI & NGHIỆM THU

### 3. Các bước sửa cấu trúc Heading cho 7 dòng tiêu đề

Bôi đen từng dòng tiêu đề và sử dụng phím tắt tương ứng để đưa về đúng 3 cấp:

"1. Thông tin chung hội nghị" 
→
→ Nhấn Ctrl + Alt + 1 (Heading 1)

"1.1. Tên hội nghị" 
→
→ Nhấn Ctrl + Alt + 2 (Heading 2)

"1.2. Thời gian & địa điểm" 
→
→ Nhấn Ctrl + Alt + 2 (Heading 2)

"2. Cơ cấu ban tổ chức" 
→
→ Nhấn Ctrl + Alt + 1 (Heading 1)

"2.1. Ban Nội dung" 
→
→ Nhấn Ctrl + Alt + 2 (Heading 2)

"2.1.1. Tiểu ban Kỹ thuật" 
→
→ Nhấn Ctrl + Alt + 3 (Heading 3)

"3. Lịch trình sự kiện" 
→
→ Nhấn Ctrl + Alt + 1 (Heading 1)

(Sau khi gán xong, vào References 
→
→ Table of Contents để chèn lại mục lục tự động hiển thị đủ 3 cấp).

### 4. Khắc phục bẫy dữ liệu số trang (Mục '3. Lịch trình sự kiện' bị dịch chuyển)

- Hiện tượng: Nếu viết thêm nội dung đẩy mục này từ trang 2 sang trang 4, bảng mục lục cũ sẽ không tự động cập nhật số trang mới.

- Thao tác xử lý:

Nhấp chuột vào bảng mục lục.

Chọn Update Table

Chọn Update entire table để Word quét lại và cập nhật chính xác toàn bộ số trang mới.
